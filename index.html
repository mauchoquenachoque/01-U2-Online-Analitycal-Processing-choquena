Conceptos Clave de OLAP

1. Hipercubo Multidimensional: Estructura donde los datos se indexan por múltiples ejes (dimensiones) que intersectan en celdas con valores cuantitativos (medidas).

2. Slice: Fija el valor de una dimensión para aislar un plano bidimensional de análisis.

3. Dice: Aplica rangos de valores sobre dos o más dimensiones generando un subcubo.

4. Drill-Down / Roll-Up: Navegación jerárquica vertical entre niveles de abstracción y detalle.

5. Pivot: Rotación del cubo cambiando la orientación dimensional para descubrir correlaciones no evidentes.
